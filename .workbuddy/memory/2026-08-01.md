# 2026-08-01

## v6 大改 — 6项改造需求全部完成

用户提出6项改造需求，全部实现并部署。

### 1. 全局搜索筛选bug修复
- **根因**：所有带搜索栏的页面（客户资料/产品库存/客片管理/拍摄计划）的`oninput="refreshView()"`触发整个view重新渲染，input被销毁重建导致无法输入
- **修复**：引入全局`searchVals`对象持久化搜索值，渲染时设置input的value属性，渲染后调用`restoreSearchFocus()`恢复焦点和光标位置

### 2. 收支记录饼图重做
- 旧`pieChart()`替换为`pieChartFloat(items,title,mode)`：CSS `filter:drop-shadow()`浮动阴影 + hover上浮效果
- 去掉饼图上的收入/支出切换按钮
- 点击饼图扇区可直接筛选列表（`finPieSlice`变量记录选中扇区）
- 切换全部/收入/支出时饼图联动更新（全部=收支占比饼图，收入=收入分类饼图，支出=支出分类饼图）

### 3. AI话术助手改为可编辑模板库
- `AI_SCENARIOS`替换为`AI_TEMPLATES`：6个美妆场景模板（新品推荐/预约提醒/售后回访/活动推广/肤质咨询/价格沟通）
- 内容从美容改为美妆
- 每个模板有可编辑textarea + 复制按钮，`updateTemplate()`实时更新

### 4. 脚本标题从选题库匹配
- 使用`<datalist id="topicList">` + `<input list="topicList">`实现输入查找匹配选择

### 5. 脚本库重构为脚本管理
- 合并旧`shootDrafts`+`scripts`为统一`scripts`数组，每个脚本含`storyboard`字段
- 统一列表展示（标题/类型/日期/状态）
- 点击脚本名称→进入分镜拍摄编辑页（`enterStoryboard()`/`exitStoryboard()`）
- 点击编辑→编辑外层表单
- 拍摄完成的脚本显示"一键发布"按钮→转入发布管理（`scriptPublish()`）
- "内容日历"重命名为"发布管理"
- 数据迁移逻辑在`loadData()`中自动处理

### 6. 首页发布状态看板 + 发布管理双下拉筛选
